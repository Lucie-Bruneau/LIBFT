# Description

Libft is a 42 project where I recreate standard C library functions and create additional utility functions in C.

# Instructions

To compile the library, run:

bash
make


# Available commands

make : compile the library.
make clean : remove object files.
make fclean : remove all generated files.
make re : recompile the library.
